# SsoClient

SSO client for Laravel: Authorization Code + PKCE login, RS256/JWKS or HMAC token validation, user sync and back-channel Single Logout.

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/laravel-sso-client
```
